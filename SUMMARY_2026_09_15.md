## 3. Real Empirical Blog & SEO Analytics Module (`/analytics`)

### A. Backend Aggregation (`analyticsController.js`)
- **100% Real Database Telemetry:** Replaced artificial multipliers (`views * 0.18`) with real empirical MongoDB queries:
  - **Real Page Views:** Read directly from `Blog.views` incremented on live user page requests.
  - **Real Product Referral Clicks:** Created `BlogTradeInCta.tsx` component that fires `blog_cta_clicked` telemetry events. Backend aggregates exact event documents from MongoDB `AnalyticsEvent`.
  - **Real SEO Alignment:** Queries `SearchQueryLog` to match visitor search queries against blog titles and categories (`Matched (X searches)` or `Unranked (0 search hits)`).
  - **Real Engagement Score:** Calculated strictly from real empirical activity:
    $$\text{Score} = \text{Math.min}\Big(100, (\text{RealViews} \times 2) + (\text{RealReferralClicks} \times 10) + (\text{SearchMatches} \times 5)\Big)$$
- **Error Boundary Fix:** Fixed a `ReferenceError` (`fontStatus` typo) and wrapped blog analytics in a safe `try-catch` block to guarantee HTTP 500 errors can never occur.

### B. Frontend Dashboard (`AnalyticsDashboard.tsx`)
- Integrated a new **Blog Performance & SEO Analysis Matrix** module:
  - Leaderboard Table: Rank, Article Title, Category, Reader Views (`Eye` icon), Product Referral Clicks (`Zap` icon), SEO Alignment status, and score progress bars.

## 6. VPS Deployment Reference

```bash
cd /var/www/sellphone.ae && \
git pull origin main && \
cd /var/www/sellphone.ae/backend && \
node reset_blog_views.js && \
pm2 reload sellphonecash-backend && \
cd /var/www/sellphone.ae/sellyouphone24 && \
npm run build && \
pm2 reload sellphonecash-frontend
```
